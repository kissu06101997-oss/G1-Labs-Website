# Proposed site map

Public / → /labs/{chemistry|physics|biology} → /labs/{subject}/{experimentId} → mode chooser. /help, /accessibility, /status and locale controls are available from every public screen.

Student /learn → assignments or history → /learn/attempts/{id} → player → observations and submit. Teacher /teach → /classes/{id} → assign or report → evidence preview or audited export. School admin /school → roster, permissions and usage. District /district → aggregated schools. State /state → rollout and training. Content /author → curriculum and model review → approved publication. Protected resources apply server-side role/scope even for direct URLs.

The 3D player and keyboard-accessible HTML route share the same command contract, attempt state, rubric and offline sync semantics.
