# UX Control Inventory (Usefulness Gate)

Every visible interactive control in **G1 Virtua Labs** is listed below with its route, audience, user goal, real destination/API call, edge-state behavior, accessibility semantics, and justification. Controls without a real purpose (e.g., promo-video buttons, duplicate mode buttons on catalogue cards, fake ratings/leaderboards, ungrounded global charts) were deliberately excluded.
